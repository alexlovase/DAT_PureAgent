# PureAgent：真实 DAT、资料与 Agent 链路实验

日期：2026-10-18。本文描述本仓库实际执行的局部实验，以及据此决定的开发顺序。上游方法研究与探针另见[研究归档](../../research/20261018_netlist_audit/README.md)。

## 1. 实际输入与执行方式

选择 [Clay R6 原始硬件设计](https://github.com/ah-cog/Clay/tree/31a84237d09eb93affb9b2587ff1d5b9a2b8c6a6/Circuit/R6) 随附的原生 OrCAD 三 DAT。没有从其他格式合成 DAT。原始文件按 MIT 许可证随样例保留，型号资料按[清单](../../examples/clay_r6/datasheets.json)获取，原厂家 PDF 不重新分发。

| 输入事实 | 数量 |
|---|---:|
| 器件实例 | 133 |
| primitive | 53 |
| 完整物理脚 | 548 |
| 普通电气网络 / 端点 | 164 / 537 |
| NC 汇总端点 / NC_PINS 补入端点 | 9 / 2 |
| 对应 PDF | 11 |

PDF 覆盖 8 个 IC、D1、蓝色 LED 与 RGB LED：6 份厂家站点直连，5 份原板仓库随附的厂家文档镜像。资料绑定标明精确料号、器件家族或后缀歧义；这不等于 11 份都完成了精确订货型号绑定。

本次用会话中的真实 Agent 调用新实现的长期 `serve` 工具，按实际读取的连接和手册自主选择检查，再由另一 Agent 回读原始依据及重算。工具日志来自运行中的服务，不是预填结论回放。原板调查覆盖 4 个局部电路、14 项具体断言，执行 91 次工具查询并目读 10 张资料页面；这些次数是工具调用数，不是模型请求数或 Agent 启动数。

完整枚举了全部器件，但本次没有完成全板电气覆盖。DS4 的 RGB 极性做了逐色核对，其余 RGB 器件只查到相关边界，不能写成每个通道都已通过。没有内置模型 API 客户端或部署独立 Deep Agents harness；本轮完成的是实际 Agent 工具编排与局部审查实验。

## 2. 原板实际调查

### U6 的 UVLO 接线

原始 `pstxnet.dat` 的完整 UVLO 网络只有 U6.7 一个端点。VAUX 则属于另一个网络，连接 U6.1 和 C32.1；没有分压、电源或控制端点给 UVLO 提供规定连接。[TI TPS61201 资料](https://www.ti.com/lit/ds/symlink/tps61201.pdf)第 4 页定义不用该功能时须接 VAUX，第 13 页解释欠压闭锁功能。

调查和独立复核均支持：**所提供网表未实现手册要求的 UVLO 接线。** 这是一项可决定的连接错误，不需要完整开关变换器 SPICE 模型，不需要猜真实负载或工作点。结论没有扩展为成品板必然损坏或必然无法启动。

### 未进入确认报告的事项

| 局部问题 | 实际证据 | 结论为何不能提升 |
|---|---|---|
| U6 的 GND / PGND | 网表中为 GND 与 GND_EARTH 两网；PGND 侧 7 个成员已完整读取。厂家要求 PCB 单点连接。 | 还需 PCB 铜箔或网桥证据。DAT 不能证明实际 PCB 未连接，也不能证明要求已满足。 |
| DS1 的 R1=30 Ω | 支路在外部 CHG_IN 输入端，经 DS1 回地；已核对其与 D1、C3、U1 的全部连接。 | 外部输入和适用 LED 特性不足。不能凭典型曲线或把输入脚规定范围当实测电压，报告原板已过流。 |
| U1 控制网名称交叉 | 物理脚 4/5 与网名 EN_B/USB_SEL 不同；三 DAT 的物理映射一致。 | 需要固件 GPIO 约定或设计意图；命名本身不是电气错误。 |
| RGB 电流裕量 | 名义设定约 9.90 mA；厂家对三色同时直流工作的限制是每色 10 mA。 | 还缺实际缩放/PWM、输出余量、温度和容差；不确认过流，也不证明可靠性通过。 |

这些事项保存在内部调查/复核记录。工程师的电气错误列表不会混入“没找到封装、型号或 datasheet”等信息。

### 真正执行的共享核算

| 对象 | 已执行关系与结果 | 输出状态 |
|---|---|---|
| U1 + R6 | `2500 AΩ / 3000 Ω ≈ 0.833333 A`，满速充电的名义设定。 | `conditional`，源选择、压差、电池和热条件未建立。 |
| U4 + R15 + RGB LED | `58.5 × 1.3 V / 7680 Ω ≈ 9.90234375 mA`，名义单通道设定。 | `conditional`，不等于实际峰值或 PWM 平均电流。 |
| DS1 + R1 | 在明确假设 CHG_IN=4.5 V 的场景，若电流为15mA，则 LED 需要 `4.5−0.015×30=4.05 V` 压降。 | `conditional`，只是负载线门槛，不是用固定 VF 预测实际电流。 |

三项均调用了算术工具，调查者另用 Decimal 重算，复核者又重新核对来源与算术。实际记录见[调查](../../runs/20261018_clay_r6/original/investigation.json)与[复核](../../runs/20261018_clay_r6/original/reviews.json)。公式来源分别是 LM3658 第 4/8 页、IS31FL3236 第 11 页，以及实际 R1 接线与条件场景。Lite-On 第 2 页的全三色限制已目读脚注。

普通无源与相关 IC/二极管共用一次关系核算，不逐个启动 Agent。R6 不需要独立建造完整电阻型号模型，才能核对充电设定；但没有电阻额定功率，就不能顺带宣称功耗符合某个任意厂家规格。

## 3. 真实接入暴露的问题与已做修复

| 问题 | 本次实际证据 | 已实现行为 |
|---|---|---|
| 把 NC 当普通网络会形成假短路 | 原始 NC 分组收录 9 个互不连接的脚；另有 2 个天线脚只声明在 NC_PINS。 | 单独保留 NC 事实，普通遍历不导通它们；保留全部 548 个物理脚。 |
| 默认摘要容易丢尾项 | GND 103 端点、VCC 85 端点、MCU 100 脚。 | 返回准确总数和 `next_offset`，可完整恢复。独立比较全部端点多重集，防止数目相同却连错。 |
| 冲突属性、重复端点和混合快照会污染事实 | 独立审计用受控文本复现了 3 种静默错误。 | 明确拒绝冲突物理脚声明、同网重复物理端点及已知实例 occurrence path 不一致，修复后独立复测。 |
| 下载成功不等于资料有效 | ISSI/TDK 旧链接返回 HTML；部分其他厂家链接无法取得 PDF。 | 验证文件头、可打开性和文档内容；使用来源清楚的原板厂家文档镜像，保留下载失败原因于内部。 |
| 资料“接近型号”不等于精确绑定 | LB QH9G 的 N100/N1OO 字符差异；U8 的 W25Q 家族信息不足。 | 保留原始值和绑定范围。只限制依赖这个区别的断言，不阻断全板查询。 |
| 失效前提会污染下游电压判断 | 原板的 UVLO 接线已经不满足要求，型号标称 3.3 V 不能自动成为板上 VCC。 | 图层不从名称/型号赋实际电压；计算有明确适用状态，未知/失效不提供可用值，条件值单独保留。 |

格式语义依据为 Cadence Capture 16.6 用户手册第 415/474 页。独立解析证据见 [parser_independent_review.json](../../runs/20261018_clay_r6/parser_independent_review.json)。

已保留原始属性、层次定位和获取校验资料，默认 Agent 视图只提供当前查询需要的连接和值；没有将文件摘要、封装描述等反复附在每个器件或每次工具响应上。完整事实保留与减少模型上下文同时实现。

## 4. 受控变体

在原始输入副本上移动一处接线，生成 B；再对 B 移除 53 处 `JEDEC_TYPE` 封装文本，生成 C。测试真值由协调方留存，调查者只读各自 DAT 和资料，之后交独立复核。具体改动由[生成脚本](../../examples/clay_r6/make_variants.py)明确记录，原板文件不变。

此对照用于验证两件事：明确接线错误能否被真实调查与复核识别；无关身份字段缺失是否妨碍同一结论。它不测全板召回率，也不把植入问题归咎于原板。

| 输入 | 独立确认 | 对照结果 |
|---|---:|---|
| [原板](../../runs/20261018_clay_r6/original/report.md) | 1 | UVLO 接线要求未满足。另两项候选维持未确定。 |
| [变体 B](../../runs/20261018_clay_r6/case_b/report.json) | 2 | 保留原有 UVLO 问题，另检出植入的 FB 断开。 |
| [变体 C](../../runs/20261018_clay_r6/case_c/report.json) | 2 | 删除 53 个独立封装属性后，同样两项接线错误仍被确认。 |

B/C 的完整引脚与连接事实逐项一致。此对照保留了 `VALUE=TPS61201DRCT`、primitive 标识和物理脚映射，因此证明的是：已有充分依据时，缺少独立 `JEDEC_TYPE` 字段可以继续完成这两项检查。它没有验证型号和物理映射也全部未知的情况。

原板与变体的最终确认数、确定性回放和测试结果保存在[实验汇总](../../runs/20261018_clay_r6/verification.json)。各自的 `report.json` 只列确认电气错误；未确认项仍可在 `investigation.json/reviews.json` 回查。

## 5. 后续按这些边界开发

### 第一步：把现有工具接入实际运行底座

保持一次图加载和可复用 PDF 对象。主审查从完整实例清单组织功能电路任务，记录未调查、条件不足及已核断言；候选交独立复核。普通阻容随电源、反馈、偏置、滤波或驱动支路处理。身份信息与当前断言无关时继续工作。

接口已经可运行；下一步接上模型客户端和任务调度，才能测真实模型轮数、tokens、耗时和成本。当前没有依据给出去掉哈希的加速倍数。91 次工具调用包含研究阶段的大量原文核对，不可当作优化完成后的产品吞吐指标。

### 第二步：把物理条件与计算依赖联系起来

当前计算工具是带来源的标量算术，不是自动电路求解器。它不证明资料适用、单位正确、工作模式成立或支路闭合；这些由调查与独立复核承担。下一阶段应让每个计算依赖明确对应实际网络、所有相关支路和工况，失效的调节前提只阻止依赖它的实际电压/电流结论。

二极管也按具体断言建模：极性和必要连接可直接核对；已知电流下的限值、恒流 LED 支路可用适用参数和约束；真正求非线性 DC 工作点时再接入可验证求解器。静态不等于线性，不统一给二极管设 0.7 V，也不以单个典型 VF 拼出全温度 I–V 曲线。

### 第三步：扩大真实输入和检查覆盖

现有适配器只验证了 Clay R6 的单 section 方言。先增加含多单元、异构脚组、其他 `PIN_NUMBER/POWER_PINS` 写法的真实导出文件，再实现对应解析与全集对照。未支持输入当前明确停止，避免静默猜映射。

电气检查扩展以新板实际任务驱动：无源值/应力、运放线性区与端口限制、开关管导通条件等，各自使用适合的关系。没有必要先为所有料号建立庞大模型库。新增功能必须保留已有的原始事实、完整可展开边界、局部信息缺失策略与独立确认报告行为。

## 6. 验证的含义

本次已将完整端点、NC 语义、分页尾项、未知邻接器件、无关身份缺失、无效模式和报告过滤等关键契约写成可执行回归，并在真实输入上完成实际 Agent 调查/独立复核。运行方式见[样例说明](../../examples/clay_r6/README.md)。

重放保存的表达式和复核记录只验证算术与呈现通路。独立复核身份、source 字段非空等结构检查不能自动证明电气结论正确；本次真实结论来自实际回读和核算。全板有效覆盖、模型 API 费用和复杂器件非线性模型仍需下一阶段实测。
