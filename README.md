# DAT_PureAgent

Agent 主导的、证据可追溯的静态网表审查方案。

**目标：输入同一设计快照的三份 DAT，结合给定 datasheet，输出逐条核查后成立的错误。** datasheet 可随任务提供，也可预先放入项目的受限资料库。

## 当前状态

2026-10-19：新增独立灵活性审计与两份真实 PCIe 相关网表实验。OpenCellular 原生 DAT（68 器件 / 348 物理脚）与 J401 fixture 导出（728 器件 / 2490 物理脚）通过全量事实比对；修复多 section 支持、局部库声明不完整、争议端点可见性、重复记录，以及计算/报告/资料索引中过严的字段要求。见 [PCIe 实验与改进方向](docs/research/20261019_pcie_flexibility.md)及[复现入口](research/20261019_pcie_audit/README.md)。选定 PCIe 范围没有确认原板电气错误，不能据此称为整板通过。

2026-10-18：已有可运行的原生 DAT 接入/查询、PDF 页面、带条件计算和确认报告工具。选用真实 Clay R6 三 DAT 与对应厂家资料，由本次会话的真实调查 Agent 和独立复核 Agent 完成局部电路实验，并保留实际调用记录。见[真实链路实验与开发决策](docs/research/20261018_real_chain.md)及[样例与运行方式](examples/clay_r6/README.md)。

本轮验证范围是工具与局部调查闭环。尚未接入独立 Deep Agents/模型 API 运行底座、全板任务调度或完整非线性工作点求解，不能直接把工具命令当成一键全板检查程序。

此前对三套开源项目的研究另见[研究决策与独立审计](docs/research/20261018_audit_decisions.md)和[可复现探针](research/20261018_netlist_audit/README.md)。探针结果与真实板卡实验分别记录。

2026-10-14：已归档 V1 方案，尚未实现检查程序、安装或适配 Skills，也未完成真实板卡查错验收。自进化仅保留后续方案，不启用。

本仓库独立保存 Agent 路线，不修改或替换 `alexlovase/DAT_Check`、`alexlovase/DAT_check_2` 的现有内容。

## 初版拟采用的执行形态

运行底座拟采用 Deep Agents Python SDK。主审查从完整实例与待查清单组织局部电路任务；调查角色查询真实连接、按需读取资料并计算；复核角色回到原始连接和资料确认具体结论，最后生成仅包含确认错误的电气报告。方案中的本地 Skill 名称是待适配名称，不代表已有可运行包。

## 已有工具

- `pureagent/dat.py`：原生三 DAT 事实与完整可展开查询，单次会话解析一次。
- `pureagent/pdf_tools.py`：有效 PDF 检查、文本搜索、整页阅读、页面渲染，复用已打开资料。
- `pureagent/calculations.py`：保留来源、假设和适用条件的受限标量算术；失效和未知模式不产生可用值。
- `pureagent/report.py`：根据已经独立复核的记录筛选工程师报告；不是独立电气判定器。
- `pureagent/cli.py`：长期 JSONL 工具会话，可由真实 Agent 调用；调用轨迹不保存整页厂家文档。

从仓库根目录运行 `python -m unittest discover -s tests -v` 验证关键契约。公开设计、资料获取脚本与真实实验记录分别在 `examples/clay_r6/` 和 `runs/20261018_clay_r6/`。

## 实施原则

正向执行通路优先；初版应具备完整调查与复核闭环，但不建设完整器件模型库、全局事实审批平台或自进化系统。任务边界、补读顺序与计算方法允许调整；升级由已归因的问题驱动。

保留原始网名、物理脚与连接，不猜测未知板外状态。资料不足只影响相关结论，不阻止其他调查；未确定项留在内部记录，不自动变成用户报告中的警告。

“已确认”指有输入证据支持并经独立复核，不是形式证明或零误报保证。没有确认发现只表示本次已核查范围内未发现可确认错误，不构成整板安全认证。
